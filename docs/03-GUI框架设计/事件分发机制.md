# 事件分发机制

## 事件系统（EventBus）

基于类型的发布/订阅，所有事件通过 `EventBus` 分发。

```cpp
// 订阅（返回 RAII Connection，析构自动断开）
Connection conn = EventBus::Get().Subscribe<MouseButtonEvent>(
    [](const MouseButtonEvent& e) { ... });

// 发布（同步，主线程）
EventBus::Get().Post(MouseButtonEvent{MouseButton::Left, true, x, y});

// 线程安全延迟发布（从 CAN/工作线程）
EventBus::Get().PostDeferred(SpeedChangedEvent{120.0f});
// 下一帧 FlushDeferred() 时在主线程分发
```

### Connection 生命周期

```cpp
class MyWidget {
    ConnectionGroup m_connections;

    void Init() {
        m_connections.Add(EventBus::Get().Subscribe<ThemeChanged>(...));
        m_connections.Add(EventBus::Get().Subscribe<KeyEvent>(...));
    }
    // 析构自动断开所有订阅，无需手动管理
};
```

### 主循环事件流

```
FlushDeferred()       ← 分发上一帧从工作线程投递的延迟事件
Post(FrameBeginEvent) ← UIContext 重置瞬时状态
PollEvents()          ← SDL 事件 → Post(MouseMove/Key/...) + Post(SDLRawEvent)
ImGui NewFrame
Post(AppTickEvent)    ← 触发动画/逻辑更新
Scene Update/Draw
ImGui Render
SwapBuffers
```

## 输入状态管理（UIContext）

`UIContext` 通过订阅 EventBus 事件维护鼠标状态（不再直接处理 SDL 事件）：

| 状态 | 含义 | 持续时间 |
|------|------|---------|
| `mouseDown` | 鼠标左键当前是否按住 | 持续到释放 |
| `mousePressed` | 本帧是否刚按下 | 仅一帧 |
| `mouseReleased` | 本帧是否刚释放 | 仅一帧 |

## Hot / Active 机制

- **Hot**：鼠标悬停在控件上（每帧重新判断）
- **Active**：鼠标按下在控件上（持续到释放）

```
鼠标移入 → Hot = widget_id
鼠标按下 → Active = widget_id
鼠标释放 → 如果 Active == Hot == widget_id → 触发点击
```

## 已定义的事件类型

| 事件 | 来源 | 用途 |
|------|------|------|
| `FrameBeginEvent` | Application | UIContext 重置状态 |
| `AppTickEvent` | Application | 动画/逻辑更新 |
| `MouseMoveEvent` | PAL/SDL2 | 鼠标位置追踪 |
| `MouseButtonEvent` | PAL/SDL2 | 点击/拖拽 |
| `MouseScrollEvent` | PAL/SDL2 | 滚轮 |
| `KeyEvent` | PAL/SDL2 | 键盘输入 |
| `WindowCloseEvent` | PAL/SDL2 | 关闭窗口 |
| `WindowResizeEvent` | PAL/SDL2 | 窗口尺寸变化 |
| `SDLRawEvent` | PAL/SDL2 | ImGui 透传 |
| `ThemeChangedEvent` | ThemeManager | 主题切换通知 |
| `LanguageChangedEvent` | I18n | 语言切换通知 |
