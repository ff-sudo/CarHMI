# 框架架构总览

## 分层模块化架构（v0.2+）

```
┌──────────────────────────────────────────────────────────┐
│  apps/gallery/          Gallery 演示程序                   │
├──────────────────────────────────────────────────────────┤
│  modules/gui/           GUI 框架 (CarHMI::GUI)            │
│    Widget + 11控件 + Layout + Style + I18n + FocusManager │
├──────────────────────────────────────────────────────────┤
│  modules/core/          核心运行时 (CarHMI::Core)          │
│    EventBus / Connection / Property / Animation / Scene   │
│    ResourceManager                                       │
├──────────────────────────────────────────────────────────┤
│  modules/rhi/           渲染抽象 (CarHMI::RHI)            │
│    Shader / Texture2D / BatchRenderer2D / Font            │
├──────────────────────────────────────────────────────────┤
│  modules/pal/           平台抽象 (CarHMI::PAL)            │
│    Platform 接口 + SDL2 后端                              │
├──────────────────────────────────────────────────────────┤
│  modules/renderer3d/    3D 渲染 (CarHMI::Render3D)        │
│    Camera / Mesh / Renderer3D (Blinn-Phong)              │
└──────────────────────────────────────────────────────────┘
预留：modules/runtime/ | modules/script/ | modules/pipeline/
```

## 依赖方向（单向向下）

```
Gallery → GUI → Core → (无依赖)
              → RHI → (无依赖)
         PAL → Core（EventBus 发事件）
Renderer3D → RHI
```

## 关键子系统

| 子系统 | 位置 | 职责 |
|--------|------|------|
| EventBus | `core/event_bus.h` | 类型化发布/订阅，RAII Connection，线程安全 PostDeferred |
| Property | `core/property/` | 响应式属性、OnChanged 回调、脏标记、线程安全写入 |
| Animation | `core/animation/` | Tween/PropertyTween/Sequence/Parallel + Easing |
| SceneManager | `core/scene/` | 页面栈 push/pop/replace + 过渡动画 |
| ResourceManager | `core/resource_manager.h` | 统一寻址、缓存、引用计数 |
| ThemeManager | `gui/style/` | JSON 主题加载 + 热重载 |
| FocusManager | `gui/focus_manager.h` | Tab/方向键/滚轮焦点导航 |
| I18n | `gui/i18n/` | 语言资源 + SheenBidi BiDi |

## 构建

```bash
cmake --preset dev-win
cmake --build build/dev-win
```
