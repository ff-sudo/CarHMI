# 框架架构总览

## 分层架构

```
┌──────────────────────────────────────────────────┐
│  Application          生命周期管理                │
│    src/core/application.h/cpp                    │
├──────────────────────────────────────────────────┤

│    src/platform/platform.h (接口)                │
│    src/platform/sdl2/ (SDL2 实现)                │
├──────────────────────────────────────────────────┤
│  EventBus             全局事件总线（eventpp）      │
│    src/core/event.h  event_bus.h                │
│    SubscriptionHandle 自动取消订阅               │
├──────────────────────────────────────────────────┤
│  Property System      属性 + 数据绑定             │
│    src/core/property/                           │

├──────────────────────────────────────────────────┤

│  GUI 层                                         │
│    Widget 基类 + 11 个控件 + Layout + Style       │

├──────────────────────────────────────────────────┤
│  I18n + RTL           国际化 + 双向文本            │
│    src/i18n/i18n.h (资源管理)                    │

├──────────────────────────────────────────────────┤
│  Animation            动画系统                    │
│    Tween / PropertyTween / Sequence / Parallel   │
│    src/animation/                               │
├──────────────────────────────────────────────────┤
│  Renderer             2D 批量渲染 + 字体           │
│    BatchRenderer2D (矩形/圆/圆弧/线段)            │
│    src/renderer/                                │
└──────────────────────────────────────────────────┘
```

## 主循环流程

```
Application::Run()
  ├── Platform::Init() + CreateWindow()
  ├── Renderer::Init() + Font::Load()
  ├── UIContext::Init() (订阅 EventBus)
  ├── FocusManager::Init() (订阅键盘/滚轮)
  ├── OnInit() (加载主题, push 初始 Scene)
  └── while (running)
        ├── EventBus.post(FrameBeginEvent)
        ├── Platform::PollEvents() → EventBus 派发所有输入事件
        ├── ImGui NewFrame
        ├── AnimationManager::Update(dt)
        ├── ThemeManager::CheckHotReload() (~每60帧)
        ├── SceneManager::Update() → Scene::OnUpdate/OnImGui
        ├── Renderer::Begin(proj) → Scene::OnDraw → Renderer::End()
        ├── ImGui Render
        └── Platform::SwapBuffers()
```

## 关键设计决策

- **Retained Mode GUI** — 控件树持久存在，适合车机固定布局
- **Property System** — 统一属性访问/监听/绑定，减少胶水代码
- **EventBus** — 发布/订阅解耦，SubscriptionHandle 自动取消
- **Platform 抽象** — SDL2 作为可替换实现层
- **页面栈** — 类 Android Activity 的 push/pop 导航
- **主题热重载** — JSON 定义样式，运行时修改即时生效
- **焦点系统** — Tab/方向键/旋钮导航，控件支持 OnFocusActivate/OnFocusAdjust
- **I18n + RTL** — JSON 语言资源，SheenBidi 双向文本，布局方向自动适配
