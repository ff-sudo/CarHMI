# 属性系统

## 设计目标

统一控件属性的访问、监听和绑定，替代手动回调同步。

## 核心类

```
modules/core/include/core/property/
├── property_base.h    — 类型擦除基类
├── property.h         — Property<T> 模板（值 + onChange + 脏标记 + 线程安全）
├── property_map.h     — 属性容器（name → Property 映射）
└── binding.h          — Binding / BidirectionalBinding / BindingScope
```

### Property\<T\>

```cpp
Property<float> speed("speed", 0.0f);

// 监听变化（返回 Connection，RAII 自动管理生命周期）
Connection conn = speed.OnChanged([](const float& old, const float& now) {
    spdlog::info("speed: {} -> {}", old, now);
});

// 赋值触发通知
speed.Set(120.0f);

// 脏标记模式（高频写入，帧末统一通知）
speed.SetDeferred(121.0f);  // 仅标 dirty
speed.SetDeferred(122.0f);  // 覆盖，仍只 dirty
speed.Flush();              // 此时触发一次回调（0 → 122）

// 线程安全写入（从 CAN/工作线程）
speed.SetFromThread(130.0f); // mutex 保护，Flush 时应用

// 循环安全：A→B→A 通知链不会无限递归
```

### PropertyMap

每个 Widget 持有一个 PropertyMap，控件构造时注册属性：

```cpp
m_propValue = m_props.Register<float>("value", 0.0f);

// 外部可按名字访问
widget->Props().Set<float>("value", 50.0f);
```

### 数据绑定

```cpp
// BindingScope — 作用域绑定，析构自动解除
BindingScope scope;

// 单向绑定
scope.Bind(slider.ValueProperty(), gauge.ValueProperty());

// 带变换
scope.Bind<float, float>(source, target,
    [](const float& v) { return v / 240.0f; });

// 格式化绑定
scope.BindFormat(slider.ValueProperty(), label.TextProperty(), "Speed: %.0f km/h");

// 双向绑定
scope.BindBidirectional(sliderA.ValueProperty(), sliderB.ValueProperty());
```

旧的全局 `BindingManager::Get()` 仍可用（向后兼容），内部委托给 BindingScope。

## Connection 与生命周期管理

```cpp
class MyScene {
    ConnectionGroup m_connections;  // 批量管理

    void OnEnter() {
        m_connections.Add(speed.OnChanged([this](...) { ... }));
        m_connections.Add(EventBus::Get().Subscribe<SpeedEvent>([this](...) { ... }));
    }
    // 场景析构 → m_connections 析构 → 全部自动断开
};
```

## 属性与动画

`PropertyTween<T>` 通过 `Property::Set()` 修改值，确保绑定链被触发：

```cpp
AnimationManager::Get().TweenPropertyTo(prop, target, 0.3f, Easing::OutCubic);
```
