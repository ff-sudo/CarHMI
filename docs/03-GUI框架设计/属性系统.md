# 属性系统

## 设计目标

统一控件属性的访问、监听和绑定，替代手动回调同步。

## 核心类

```
src/core/property/
├── property_base.h    — 类型擦除基类
├── property.h         — Property<T> 模板（值 + onChange 通知）
├── property_map.h     — 属性容器（name → Property 映射）
└── binding.h          — 数据绑定（单向 + 变换）
```

### Property\<T\>

```cpp
Property<float> value("speed", 0.0f);

// 监听变化
value.OnChanged([](const float& old, const float& now) { ... });

// 赋值触发通知
value.Set(120.0f);  // 所有 OnChanged 回调被调用

// 隐式转换
float v = value;    // 等同于 value.Get()
```

### PropertyMap

每个 Widget 持有一个 PropertyMap，控件构造时注册属性：

```cpp
// Slider 构造函数
m_propValue = m_props.Register<float>("value", 0.0f);

// 外部可按名字访问
widget->Props().Set<float>("value", 50.0f);
```

### 数据绑定

```cpp
auto& bm = BindingManager::Get();

// 直接绑定（同类型）
bm.Bind(slider.ValueProperty(), gauge.ValueProperty());

// 带变换的绑定
bm.Bind<float, float>(slider.ValueProperty(), bar.ValueProperty(),
    [](const float& v) { return v / 240.0f; });

// 格式化绑定（float → string）
bm.BindFormat(slider.ValueProperty(), label.TextProperty(), "Speed: %.0f km/h");
```

## 属性与动画

`PropertyTween<T>` 通过 `Property::Set()` 修改值，确保绑定链被触发：

```cpp
// 旧方式：绕过 Property，绑定不生效
AnimationManager::Get().TweenTo(&rawValue, target, 0.3f, ...);

// 新方式：通过 Property，绑定自动同步
AnimationManager::Get().TweenPropertyTo(prop, target, 0.3f, ...);
```
