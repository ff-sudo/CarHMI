# 控件树设计

## 控件层级

```
Widget (基类)
  ├── Panel           容器面板
  ├── BoxLayout       自动布局容器（VBox/HBox）
  ├── Label           文字标签（Role: Text/Title/Subtitle/Custom）
  ├── Button          按钮（hover/press 动画过渡）
  ├── Slider          滑块（拖拽 + 焦点滚轮调值）
  ├── ProgressBar     进度条
  ├── Toggle          滑动开关（动画过渡）
  ├── Gauge           圆弧仪表盘（指针 + 颜色分级）
  ├── Knob            旋转选择器
  ├── TabBar          标签栏切换
  └── ListWidget      可滚动列表
```

## Widget 基类能力

| 能力 | 方法 |
|------|------|
| 属性系统 | `Props()` → PropertyMap，`Register/Get/Set by name` |
| 焦点支持 | `m_focusable`，`OnFocusActivate()`，`OnFocusAdjust(delta)` |
| 主题响应 | `ApplyTheme()`，`SubscribeThemeChange()` |
| 碰撞检测 | `Contains(point)` 基于绝对坐标 |
| 树结构 | `AddChild()`，相对坐标，递归 Update/Draw |

## 坐标系

相对坐标系：`m_pos` 相对父容器，`GetAbsolutePos()` 递归累加。

## 焦点导航

- `FocusManager` 管理焦点链（所有 `m_focusable=true` 的控件）
- Tab/方向键切换焦点，Enter/Space 激活，鼠标滚轮调值
- 焦点控件显示蓝色边框高亮

## 属性系统

每个控件通过 `PropertyMap` 暴露属性（如 `value`、`text`），支持：
- `OnChanged` 监听
- `BindingManager` 数据绑定
- `PropertyTween` 动画驱动
