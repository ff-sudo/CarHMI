# 3D 场景渲染

## 架构

```
src/renderer3d/
├── camera.h         轨道摄像机（旋转/缩放/平移）
├── mesh.h/cpp       OBJ 模型加载 + GPU 缓冲管理
└── renderer3d.h/cpp Blinn-Phong 光照渲染管线

resources/shaders/
├── phong.vert       3D 顶点着色器（MVP 变换 + 法线矩阵）
└── phong.frag       Blinn-Phong 片段着色器（漫反射贴图支持）
```

## Camera 轨道摄像机

围绕目标点旋转的摄像机，适合 3D 模型查看：

```cpp
Camera cam(50.0f, -90.0f, 20.0f);  // distance, yaw, pitch
cam.Orbit(dx, dy);   // 鼠标拖动旋转
cam.Zoom(scroll);    // 滚轮缩放
cam.Pan(dx, dy);     // 中键平移
```

内部用球坐标计算相机位置：`position = target + spherical(yaw, pitch) * distance`

## Mesh + OBJ 加载

使用 **tinyobjloader** 解析 OBJ/MTL 文件：
- 支持多 shape、多材质
- 自动加载 `map_Kd` 指定的漫反射贴图（stb_image）
- 顶点去重（position/normal/texcoord 组合哈希）
- 自动计算包围球（center + radius）用于相机定位

顶点格式：`{vec3 position, vec3 normal, vec2 texCoord}`

每个 SubMesh 对应一个 shape + 材质，独立的 VAO/VBO/EBO。

## Blinn-Phong 光照

```
ambient  = Ka * 0.3
diffuse  = max(dot(N, L), 0) * Kd * lightColor
specular = pow(max(dot(N, H), 0), shininess) * Ks * lightColor
```

H = normalize(L + V)，半程向量，比 Phong 反射更自然。

支持漫反射贴图（`u_HasDiffuseMap`），baseColor 从纹理采样。

## 3D 与 2D 渲染的共存

Application 主循环中，每个 Scene 完全管理自己的渲染：
- 2D Scene：调用 `BatchRenderer2D::Begin/End` + 正交投影
- 3D Scene：调用 `Renderer3D::Begin/End` + 透视投影 + 深度缓冲
- `glClear(COLOR | DEPTH)` 统一清除

```
Application::Run loop:
  glClear(COLOR | DEPTH)
  SceneManager::Draw()      ← Scene 自己决定用 2D 还是 3D 渲染
  ImGui Render
  SwapBuffers
```
