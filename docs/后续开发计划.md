# 后续开发计划

## 待修复问题

### 1. 中文/阿拉伯文字体渲染
- **状态**：动态字形缓存已实现，但非 ASCII 字符不显示
- **排查方向**：验证 stbtt_FindGlyphIndex 返回值、检查 atlas 像素数据、用 RenderDoc 查 GPU 纹理
- **优先级**：高

### 2. 样式主题切换不完全
- **状态**：手动 SetColors() 的控件不跟随主题变化
- **方案**：ProgressBar 的颜色阈值逻辑改为从主题读取 warning/danger 颜色
- **优先级**：中

### 3. LanguageChangedEvent 未被订阅
- **状态**：语言切换需要重新进入 Scene 才生效
- **方案**：Widget 基类订阅 LanguageChangedEvent，自动刷新 I18n 绑定的文本属性
- **优先级**：中
