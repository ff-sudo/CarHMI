# 车机 HMI 实战

> 本章节为预留，待 Phase 5 实施后补充。

## 计划内容

- 仪表盘主界面设计（Gauge + 速度/转速/油量）
- 中控导航/媒体/电话多页面
- 3D 车辆模型展示（360° 旋转查看）
- CAN 信号模拟（ImGui 面板模拟车辆数据源）
- 页面切换过渡动画
- 完整的主题适配（Dark/Light）

## 当前已有的基础

已实现的控件和系统足够搭建完整 HMI：
- Gauge 仪表盘、Knob 旋钮、Toggle 开关、TabBar 标签栏、List 列表
- SceneManager 页面栈导航
- 属性系统 + 数据绑定
- 动画系统（Tween + 过渡）
- 样式系统（JSON 主题 + 热重载）
- 焦点/旋钮导航
- 3D 渲染（OBJ 加载 + Blinn-Phong 光照）
