# 渲染管线概览

## OpenGL 3.3 Core Profile 渲染管线

```mermaid
graph LR
    VBO[顶点数据 VBO] --> VS[顶点着色器]
    VS --> RAST[光栅化]
    RAST --> FS[片段着色器]
    FS --> TEST[深度/模板测试]
    TEST --> BLEND[混合]
    BLEND --> FB[帧缓冲 → 屏幕]
```

可编程阶段只有两个：**顶点着色器**和**片段着色器**。其他阶段由 OpenGL 固定管线处理。

---

## 1. 缓冲对象

### VBO — Vertex Buffer Object

存储顶点数据的 GPU 端缓冲区。

```cpp
GLuint vbo;
glGenBuffers(1, &vbo);
glBindBuffer(GL_ARRAY_BUFFER, vbo);
glBufferData(GL_ARRAY_BUFFER, dataSize, data, GL_DYNAMIC_DRAW);
```

**用法提示（usage hint）：**

| 值 | 含义 | 本项目用途 |
|----|------|-----------|
| `GL_STATIC_DRAW` | 数据设置一次，使用多次 | 3D 模型顶点、EBO 索引 |
| `GL_DYNAMIC_DRAW` | 数据频繁修改 | 2D BatchRenderer 每帧更新 |

### EBO — Element Buffer Object

索引缓冲，避免重复存储共享顶点：

```
无索引：6 顶点画 1 个四边形（两个三角形，2 个顶点重复）
有索引：4 顶点 + 6 索引 → 节省 33% 顶点数据

索引模式: 0,1,2, 2,3,0
   3 ---- 2
   |    / |
   |  /   |
   0 ---- 1
```

```cpp
glGenBuffers(1, &ebo);
glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, ebo);
glBufferData(GL_ELEMENT_ARRAY_BUFFER, indexSize, indices, GL_STATIC_DRAW);
```

### VAO — Vertex Array Object

记录 VBO 的顶点属性布局，绑定一次后续只需绑 VAO 即可恢复所有属性状态。

```cpp
GLuint vao;
glGenVertexArrays(1, &vao);
glBindVertexArray(vao);

// 绑定 VBO 并定义属性布局
glBindBuffer(GL_ARRAY_BUFFER, vbo);

// 位置属性：location=0, 2个float
glEnableVertexAttribArray(0);
glVertexAttribPointer(0, 2, GL_FLOAT, GL_FALSE, sizeof(Vertex), (void*)offsetof(Vertex, position));

// 颜色属性：location=1, 4个float
glEnableVertexAttribArray(1);
glVertexAttribPointer(1, 4, GL_FLOAT, GL_FALSE, sizeof(Vertex), (void*)offsetof(Vertex, color));

glBindVertexArray(0);  // 解绑
```

`glVertexAttribPointer` 参数含义：

```
(index, size, type, normalized, stride, offset)
  ↓      ↓     ↓       ↓         ↓       ↓
 属性   分量数  类型  是否归一化  步长   字节偏移
```

### glBufferSubData — 部分更新

BatchRenderer 每帧只更新实际使用的顶点数据，而非整个缓冲：

```cpp
uint32_t dataSize = (uint8_t*)vertexPtr - (uint8_t*)vertexBuffer;
glBufferSubData(GL_ARRAY_BUFFER, 0, dataSize, vertexBuffer);
```

## 2. Shader 着色器

### GLSL 基础

```glsl
#version 330 core  // 必须是第一行

// 输入：从 VBO 的顶点属性读取
layout(location = 0) in vec3 a_Position;
layout(location = 1) in vec4 a_Color;

// Uniform：CPU 传给 GPU 的全局变量
uniform mat4 u_Projection;

// 输出：传给下一个阶段
out vec4 v_Color;

void main() {
    v_Color = a_Color;
    gl_Position = u_Projection * vec4(a_Position, 1.0);
}
```

### 数据类型

| GLSL 类型 | C++ 对应 | 用途 |
|-----------|---------|------|
| `float` | `float` | 标量 |
| `vec2/vec3/vec4` | `glm::vec2/3/4` | 向量 |
| `mat3/mat4` | `glm::mat3/4` | 矩阵 |
| `sampler2D` | 纹理单元索引 | 纹理采样器 |
| `bool` | `int` (0/1) | 布尔开关 |

### 编译与链接

```cpp
// 编译
GLuint shader = glCreateShader(GL_VERTEX_SHADER);
glShaderSource(shader, 1, &source, nullptr);
glCompileShader(shader);

// 检查编译错误
int success;
glGetShaderiv(shader, GL_COMPILE_STATUS, &success);
if (!success) {
    char log[1024];
    glGetShaderInfoLog(shader, sizeof(log), nullptr, log);
    // 输出错误日志
}

// 链接
GLuint program = glCreateProgram();
glAttachShader(program, vertShader);
glAttachShader(program, fragShader);
glLinkProgram(program);

// 使用
glUseProgram(program);
```

### Uniform 设置

```cpp
// 查找 uniform 位置
GLint loc = glGetUniformLocation(program, "u_Projection");

// 各类型设置方法
glUniform1i(loc, intValue);                          // int
glUniform1f(loc, floatValue);                        // float
glUniform3f(loc, x, y, z);                           // vec3
glUniform4f(loc, x, y, z, w);                        // vec4
glUniformMatrix4fv(loc, 1, GL_FALSE, &matrix[0][0]); // mat4
glUniform1iv(loc, count, intArray);                   // int 数组
```

### 本项目的 Shader

| Shader | 用途 | 关键 Uniform |
|--------|------|-------------|
| `batch2d.vert/frag` | 2D 批量渲染 | `u_Projection`, `u_Textures[16]` |
| `phong.vert/frag` | 3D Blinn-Phong 光照 | `u_Model/View/Projection`, `u_LightPos`, `u_NormalMatrix` |

## 3. 纹理

### 创建与上传

```cpp
GLuint tex;
glGenTextures(1, &tex);
glBindTexture(GL_TEXTURE_2D, tex);

// 上传像素数据
glTexImage2D(GL_TEXTURE_2D, 0, GL_RGBA8,   // 内部格式
             width, height, 0,
             GL_RGBA, GL_UNSIGNED_BYTE,      // 源数据格式
             pixelData);
```

### 格式对照

| 通道数 | internalFormat | dataFormat |
|--------|---------------|------------|
| 1 (灰度) | `GL_R8` | `GL_RED` |
| 3 (RGB) | `GL_RGB8` | `GL_RGB` |
| 4 (RGBA) | `GL_RGBA8` | `GL_RGBA` |

### 采样参数

```cpp
// 环绕模式：超出 0-1 UV 范围时的行为
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE);  // 2D GUI
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_REPEAT);         // 3D 贴图

// 过滤模式：缩放时的采样方式
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR);           // 2D
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR_MIPMAP_LINEAR); // 3D
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
```

### Mipmap

3D 渲染中，远处物体需要更小的纹理级别以避免走样：

```cpp
glTexImage2D(...);          // 上传原始尺寸
glGenerateMipmap(GL_TEXTURE_2D);  // 自动生成缩小版本
```

### 多纹理单元

GPU 可以同时绑定多个纹理（OpenGL 3.3 至少 16 个）：

```cpp
glActiveTexture(GL_TEXTURE0 + slot);  // 激活纹理单元
glBindTexture(GL_TEXTURE_2D, texID);  // 绑定纹理到该单元

// Shader 中
uniform sampler2D u_Textures[16];
// 设置采样器指向对应单元
int samplers[] = {0, 1, 2, ..., 15};
glUniform1iv(loc, 16, samplers);
```

本项目 BatchRenderer2D 用 16 个纹理单元实现多纹理批量渲染，slot 0 固定为 1x1 白色纹理（纯色渲染用）。

### GLSL 3.3 纹理数组索引限制

GLSL 3.3 **不允许**用变量索引 `sampler2D` 数组，必须用 `switch-case`：

```glsl
// 错误：部分驱动会编译失败
texture(u_Textures[int(v_TexIndex)], uv);

// 正确：显式 switch
switch (int(v_TexIndex)) {
    case 0: color = texture(u_Textures[0], uv); break;
    case 1: color = texture(u_Textures[1], uv); break;
    // ...
}
```

## 4. 坐标系统与变换

### 变换管线

```mermaid
graph LR
    LOCAL[模型坐标] -->|Model 矩阵| WORLD[世界坐标]
    WORLD -->|View 矩阵| VIEW[相机坐标]
    VIEW -->|Projection 矩阵| CLIP[裁剪坐标]
    CLIP -->|透视除法 w| NDC[标准化设备坐标 -1~1]
    NDC -->|glViewport| SCREEN[屏幕像素坐标]
```

### Model 矩阵

将模型从局部坐标变换到世界坐标：

```cpp
glm::mat4 model = glm::mat4(1.0f);
model = glm::translate(model, position);
model = glm::rotate(model, angle, axis);
model = glm::scale(model, scaleVec);
```

变换顺序从右往左读：先缩放 → 旋转 → 平移。

### View 矩阵

将世界坐标变换到相机视角：

```cpp
glm::mat4 view = glm::lookAt(
    cameraPos,   // 相机位置
    target,      // 看向的目标点
    up           // 上方向（通常 0,1,0）
);
```

### Projection 矩阵

#### 正交投影（2D）

```cpp
glm::mat4 proj = glm::ortho(
    0.0f,        // left
    (float)w,    // right
    (float)h,    // bottom (大于 top → Y 轴向下)
    0.0f,        // top
    -1.0f, 1.0f  // near, far
);
```

屏幕坐标直接映射，(0,0) 在左上角，适合 2D GUI。

#### 透视投影（3D）

```cpp
glm::mat4 proj = glm::perspective(
    glm::radians(45.0f),  // FOV 视场角
    aspect,                // 宽高比
    0.1f,                  // 近裁剪面
    1000.0f                // 远裁剪面
);
```

近大远小的真实透视效果。

### 法线矩阵

Model 矩阵如果包含非均匀缩放，法线方向会变形。需要用法线矩阵校正：

```cpp
glm::mat3 normalMatrix = glm::transpose(glm::inverse(glm::mat3(model)));
```

本项目 3D 渲染中传入 Shader 作为 `u_NormalMatrix`。

### glViewport

定义渲染输出在窗口中的区域：

```cpp
glViewport(0, 0, windowWidth, windowHeight);
// (x, y, width, height) — 左下角为原点
```

## 5. 绘制调用

### glDrawElements

用索引缓冲绘制：

```cpp
glBindVertexArray(vao);
glDrawElements(
    GL_TRIANGLES,        // 图元类型
    indexCount,          // 索引数量
    GL_UNSIGNED_INT,     // 索引类型
    nullptr              // 偏移（nullptr = 从头开始）
);
```

本项目 2D 和 3D 渲染都用 `glDrawElements`。

### Draw Call 开销

每次 `glDrawElements/glDrawArrays` 调用都有 CPU→GPU 的通信开销。
- 1000 个独立矩形 = 1000 次 draw call → 慢
- BatchRenderer 合并到 1 个 VBO = 1 次 draw call → 快

## 6. 混合（Blending）

控制新片段颜色与帧缓冲中已有颜色的混合方式：

```cpp
glEnable(GL_BLEND);
glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA);
```

混合公式：

```
最终颜色 = srcColor × srcAlpha + dstColor × (1 - srcAlpha)
```

- `srcAlpha = 1.0`：完全不透明，覆盖背景
- `srcAlpha = 0.5`：半透明，与背景混合
- `srcAlpha = 0.0`：完全透明，不可见

2D GUI 和 ImGui 需要混合（文字、半透明面板）。3D 渲染通常关闭混合。

## 7. 深度测试

决定重叠片段的前后遮挡关系：

```cpp
glEnable(GL_DEPTH_TEST);
glClear(GL_DEPTH_BUFFER_BIT);  // 每帧清除深度缓冲
```

每个片段有一个深度值（z），离相机越近深度值越小。默认 `GL_LESS`：新片段深度小于缓冲中的才写入。

3D 渲染**必须**开启深度测试。2D 渲染按绘制顺序叠加，不需要。

---

## 8. GL 状态管理

OpenGL 是状态机，`glEnable/glDisable` 切换全局状态：

```cpp
glEnable(GL_BLEND);       // 开启混合
glDisable(GL_BLEND);      // 关闭混合
glEnable(GL_DEPTH_TEST);  // 开启深度测试
glDisable(GL_DEPTH_TEST); // 关闭深度测试
```

本项目渲染模式切换：

| 场景 | 投影 | 深度测试 | 混合 | Shader |
|------|------|---------|------|--------|
| 2D GUI | 正交 | 关闭 | 开启 | batch2d |
| 3D 模型 | 透视 | 开启 | 关闭 | phong |
| ImGui | 正交 | 关闭 | 开启 | ImGui 内部 |

Renderer3D::Begin 中 `glEnable(GL_DEPTH_TEST)`，End 中 `glDisable(GL_DEPTH_TEST)`，确保 3D 渲染后不影响 2D 和 ImGui。

## 9. 帧缓冲与清除

每帧开始时清除颜色和深度缓冲：

```cpp
glClearColor(0.08f, 0.08f, 0.10f, 1.0f);  // 设置清除颜色
glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);
```

`glClearColor` 设置一次即可，不需要每帧调用（除非背景色动态变化——本项目主题切换时会改变）。

## 10. 光照模型

### Blinn-Phong

本项目 3D 渲染采用的光照模型，由三个分量组成：

```
最终颜色 = ambient + diffuse + specular
```

**Ambient（环境光）**：模拟间接光照，常量值

```glsl
vec3 ambient = Ka * 0.3;
```

**Diffuse（漫反射）**：光线与表面法线的角度关系

```glsl
float diff = max(dot(normal, lightDir), 0.0);
vec3 diffuse = diff * Kd * lightColor;
```

`dot(N, L) > 0` 表示光线照到正面，= 0 表示光线平行于表面。

**Specular（高光）**：Blinn-Phong 用半程向量 H

```glsl
vec3 halfDir = normalize(lightDir + viewDir);
float spec = pow(max(dot(normal, halfDir), 0.0), shininess);
vec3 specular = spec * Ks * lightColor;
```

`shininess` 越大，高光越集中。

### 与 Phong 的区别

Phong 用反射向量 R = reflect(-L, N)，计算 dot(R, V)。
Blinn-Phong 用半程向量 H = normalize(L + V)，计算 dot(N, H)。
Blinn-Phong 计算更快，且在大角度下高光更自然。

## 11. 资源生命周期

OpenGL 资源需要手动管理创建和销毁：

| 资源 | 创建 | 销毁 |
|------|------|------|
| VBO/EBO | `glGenBuffers` | `glDeleteBuffers` |
| VAO | `glGenVertexArrays` | `glDeleteVertexArrays` |
| Texture | `glGenTextures` | `glDeleteTextures` |
| Shader | `glCreateShader` | `glDeleteShader` |
| Program | `glCreateProgram` | `glDeleteProgram` |

本项目在各类的析构函数中调用对应的 Delete 函数，利用 C++ RAII 管理。
